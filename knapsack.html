0-1 Knapsack Problem

Solving Combinatorial Optimization using Tabu Search

Project Overview

This project focuses on the 0-1 Knapsack Problem, a classical combinatorial optimization problem. The objective is to maximize the total profit without exceeding the capacity of the knapsack.

Methodology

The problem is approached using the Tabu Search metaheuristic. The algorithm explores neighboring solutions using Add, Remove and Swap moves, while a Tabu List helps avoid cycling.
